Smart Environment Node

Sistem pemantauan lingkungan berbasis mikrokontroler yang mengumpulkan data seperti suhu, gas, dan gerakan lalu menampilkan hasilnya ke dashboard secara real-time untuk keputusan cepat dan lebih aman.

Ringkasan Proyek

Project ini menggabungkan perangkat keras dan software untuk mengumpulkan titik data lingkungan seperti suhu, gas, dan gerak. Data dikirim secara real-time ke server web dan divisualisasikan agar pengguna dapat memantau kondisi lingkungan dengan cepat dan akurat.

Poin Utama

  • Integrasi sensor untuk data lingkungan secara otomatis
  • Visualisasi real-time di dashboard web
  • Struktur backend yang siap dipantau dan dikembangkan
  • Solusi fleksibel untuk otomasi dan keamanan ruangan

Bahasa & Teknologi yang Digunakan

HTML

Menyusun struktur halaman dashboard dan antarmuka utama.

CSS

Memberikan tampilan profesional, responsif, dan modern.

JavaScript

Mengatur logika real-time, interaksi dashboard, dan komunikasi data.

C++ / Arduino

Mengolah input sensor dan mengendalikan perangkat mikrokontroler.

Arsitektur Sistem

Sensor Layer
Pengukuran suhu, gas, dan movement dari perangkat fisik.
Microcontroller
Proses data dan pengiriman ke backend melalui protokol komunikasi.
Web Dashboard
Menampilkan hasil monitoring dengan tampilan yang mudah dibaca.

Hasil yang Dicapai

  • Monitoring lebih cepat dan akurat untuk kondisi lingkungan
  • Dasbor yang dapat diakses untuk kebutuhan observasi real-time
  • Struktur sistem yang mudah dikembangkan untuk kebutuhan selanjutnya
  • Potensi integrasi dengan otomatisasi smart home atau lab
